# Project-B-Business-Operations-Analytics

## Purpose

A portfolio project demonstrating data-driven analysis for Business Operations, Sales Operations, and Commercial Operations through a B2B sales and customer onboarding use case.

## Planned analysis

- Sales funnel performance and conversion
- Customer onboarding cycle time
- Funnel drop-off and operational bottlenecks
- Operational performance trends and decision-support metrics

## Tools

- SQL
- Power BI

## Current status

Synthetic v2 data and SQL analyses are in place. Phase 1 personal SQL acceptance passed on 2026-09-20; Phase 2 Power BI acceptance passed on 2026-09-21, with a two-page dashboard reconciled against the SQL baselines. Phases 3 to 5 (findings and recommendations, portfolio packaging, interview preparation) are not started. This is a capability demonstration on simulated data, not evidence of real-company results.
